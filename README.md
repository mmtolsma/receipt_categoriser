# Receipt Categoriser

AI-assisted receipt analyser that extracts and categorises receipt items from uploaded images.

## Current Stack

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui
- React
- pnpm

## Current App State

- Next.js app scaffolded with App Router
- `shadcn/ui` initialized with the Base UI Nova preset
- starter homepage still in place

## Core MVP Flow

Planned MVP flow:

1. User uploads receipt images.
2. AI extracts receipt data and category suggestions.
3. User reviews and edits the output.
4. User accepts, retries, or declines the result.
5. Accepted data is stored for later viewing.
